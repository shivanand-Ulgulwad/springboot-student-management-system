# Student Management System

A full-stack Spring Boot MVC project with authentication, CRUD operations, pagination, validation, search, and file upload.

## Features


- Student CRUD
- Pagination
- Search
- File Upload
- Validation
- Thymeleaf UI
- MySQL Database

## Tech Stack

- Java 17
- Spring Boot
- Spring MVC
- Thymeleaf
- MySQL
- Bootstrap

1. Clone repo
2. Create MySQL database
3. Configure application.properties
4. Run project
